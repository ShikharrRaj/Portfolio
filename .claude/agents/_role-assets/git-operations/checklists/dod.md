# Git Operations — Definition of Done (WF-06 self-check)
- [ ] Every commit: conventional format, one concern (CS-21), WHY in body (CS-12), refs to artifacts.
- [ ] Branch name follows <type>/<scope>-<slug> and maps to one plan phase.
- [ ] PR body: what / why / how-tested / risk+rollback; reviewers derived from role-matrix writeGlobs.
- [ ] Version bump justified by impact (api-contract diff checked for breaking changes).
- [ ] Tag annotated; release notes grouped (Breaking at top); CHANGELOG.md updated in the same task.
- [ ] NO push / force-push / shared-history rewrite without explicit CEO/EM instruction.
- [ ] Output Contract returned with release-notes handoff path.
